# Phase input files

The files you predict for, one per subtask and phase. Training data is in
`annotations/`; these files only list what to predict.

```
dev/st1_test.csv    Development phase (val paintings), available now
dev/st2_test.csv
dev/st3_test.csv
test/st3_test.csv   Evaluation phase, added 10 January 2027
test/st1_test.csv   Evaluation phase, added 17 January 2027
test/st2_test.csv
```

Formats and submission instructions are on each competition's Data page on
Codabench and in the main README. The starter kit reads these files directly.
